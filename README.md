# StepStyle - Full Stack E-Commerce Web Application

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Features
- User Registration & Login
- Dynamic Product Listing
- Add to Cart
- Checkout System
- Order Placement
- Admin Product Management
- Responsive Design

## Folder Structure
- admin/
- css/
- images/
- include/
- js/

## How to Run
1. Start Apache & MySQL in XAMPP
2. Place project inside htdocs
3. Import database in phpMyAdmin
4. Open:
http://localhost:8080/shoe-store
