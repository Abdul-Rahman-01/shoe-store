# StepStyle - E-Commerce Shoe Store

StepStyle is a full-stack e-commerce web application developed using HTML, CSS, JavaScript, PHP, and MySQL.

## Features
- User Registration & Login
- Product Categories
- Product Details Page
- Add To Cart
- Checkout Page
- Admin Panel
- Responsive UI Design

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Project Setup
1. Install XAMPP
2. Move project folder into htdocs
3. Import database into phpMyAdmin
4. Run Apache and MySQL
5. Open localhost/shoe-store
